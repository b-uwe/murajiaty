# PWA Icons

This directory contains PWA icons for the Arabic Vocabulary Trainer app.

## Required Icons
Only these essential icon sizes are needed:

- **192x192** - Main Android launcher icon
- **512x512** - Chrome splash screen and app launcher icon

## Icon Design
- Background color: #2196f3 (Material Blue)
- Foreground: Arabic letter "م" (meem) in white  
- Style: Clean, minimal design suitable for app icons

## Creating Icons
Create PNG files with the above specifications and save as:
- `icon-192x192.png`
- `icon-512x512.png`

The fallback SVG (`icon.svg`) can be used as a template.
