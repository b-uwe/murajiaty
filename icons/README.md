# PWA Icons

This directory contains PWA icons for the Arabic Vocabulary Trainer app.

## Required Icons
The following icon sizes are needed for full PWA compatibility:

- 72x72 - Android Chrome M39+ with 0.75x density
- 96x96 - Android Chrome M39+ with 1.0x density  
- 128x128 - Chrome Web Store app icon
- 144x144 - Windows Metro tile icon
- 152x152 - Apple iPad touch icon
- 192x192 - Android Chrome M39+ and M47+ launcher icon
- 384x384 - Chrome splash screen icon
- 512x512 - Chrome splash screen and app launcher icon

## Generating Icons
1. Open `create-icons.html` in a web browser
2. Download each generated PNG file
3. Save them in this directory with the correct filenames

## Icon Design
- Background color: #2196f3 (Material Blue)
- Foreground: Arabic letter "م" (meem) in white
- Style: Clean, minimal design suitable for app icons
